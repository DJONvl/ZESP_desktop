# WingUI — справочник по оконному движку терминала

> Веб-морда живёт в `public/` (слушается на `/`). Оконный движок — **`public/js/window-engine.js`**,
> фасад в глобальной переменной **`window.WinEngine`** (IIFE; из внешних зависимостей — только `interact.js`).
> Виджеты (окна) лежат в отдельных JS-файлах и только **регистрируются** в движке.
> Движок никак не знает о конкретных виджетах — ему передаётся декларация (registry def).

Ниже — всё для жизни, разработки и поддержки: устройство движка, открытие/закрытие/настройка окна,
создание нового виджета, тулбары, ярлыки, старт-меню, таскбар, мобильный режим.

---

## 1. Как устроен движок

- `WinEngine.init()` вызывается один раз из `core.js` (в конце загрузки, после регистрации всех виджетов).
- Порядок инициализации: `applyMobileLayout()` → `restore()` (восстановление раскладки) → `initInteract()`
  → `renderStartMenu()` → `renderShortcuts()` → `renderTaskbar()` → запуск часов таскбара.
- На десктопе размер/перетаскивание делает `interact.js`; на тач-устройствах движок отключает interact
  (drag/resize) и использует собственный механизм (см. §8).
- Событие `'layout'` сигнализирует виджетам о любом изменении раскладки (см. §12).

## 2. Структура проекта веб-морды

```
public/
  index.html                     — скелет: .main > #desktop > #shortcuts, .taskbar, подключение JS
  interact.min.js                — drag/resize (десктоп)
  lightweight-charts...js        — графики
  js/
    window-engine.js             — сам движок (WinEngine)
    core.js                      — WebSocket, тема, аккаунты, header, вызовы init
    chart / trade / ai / panel / settings / prompt / account / orders / ops / watch / book
                                 — файлы-виджеты: каждый регистрирует окно(а) через WinEngine.register
```

Подключение: **сначала `window-engine.js`, затем все файлы виджетов**, в конце `core.js`
(там вызывается `WinEngine.init()`).

## 3. Registry: описание виджета (def)

```js
WinEngine.register({
  // == обязательное ==
  id: 'chart',             // тип окна (уникальный). Пишется в data-wid каждого окна.
  title: 'График',         // название в кнопке таскбара (fallback на label)
  label: 'График',         // название для ярлыка и старт-меню
  icon: '📈',              // иконка (эмодзи) для ярлыка/кнопок
  template: SOME_TEMPLATE, // HTML-строка шаблона окна (см. §5)

  // == необязательные флаги ==
  single: true,            // true = может быть только одно окно этого типа
                           // (иначе open() плодит много экземпляров одного типа)
  shortcut: false,         // false — не показывать ярлык на рабочем столе (по умолчанию показывать)
  startMenu: false,        // false — не показывать в старт-меню (по умолчанию показывать)

  // == хуки жизненного цикла (все опциональные) ==
  setup(node, opts)     { /* инициализация при создании НОВОГО окна (после вставки в DOM) */ },
  activate(node, opts)  { /* повторный open(id, opts) если окно уже есть (single),
                              либо сразу после setup для нового (single) —
                              удобно передать выбранный инструмент / фокус */ },
  destroy(node)         { /* очистка при закрытии: таймеры, подписки, listeners, Map-ы */ },
  onFocus(node)         { /* реакция на подъём окна наверх (фокус) */ },
});
```

### Сводка полей def

| Поле | Обязат. | Описание |
|------|---------|----------|
| `id` | да | тип окна (в `data-wid`) |
| `title` | да | заголовок + таскбар |
| `label` | да | ярлык + старт-меню |
| `icon` | да | эмодзи |
| `template` | да | HTML шаблон окна (корень — `.window.hidden` + `data-*`) |
| `single` | нет | только один экземпляр |
| `shortcut:false` | нет | скрыть ярлык с рабочего стола |
| `startMenu:false` | нет | скрыть из старт-меню |
| `setup(node, opts)` | нет | init нового окна |
| `activate(node, opts)` | нет | повторный open / передача параметра |
| `destroy(node)` | нет | очистка при закрытии |
| `onFocus(node)` | нет | реакция на фокус |

## 4. Публичное API `WinEngine`

Всё доступно как `WinEngine.*`:

```js
WinEngine.register(def)         // зарегистрировать виджет
WinEngine.getDef(id)            // получить def по id (или undefined)

WinEngine.open(id, opts)        // открыть / сфокусировать окно. opts:
                                //   { force:true }           — для single создать ещё одно
                                //   { pos:{x,y,w,h,minimized} } — точные координаты/размер (restore)
                                //   { anchor:element }      — открыть рядом с элементом (кнопкой)
WinEngine.close(node)           // закрыть конкретное окно (узел .window)
WinEngine.focus(node)           // поднять окно наверх
WinEngine.on('layout', cb)      // подписка на событие layout (см. §12)
WinEngine.saveLayout()          // вручную сохранить раскладку
WinEngine.restore()             // восстановить раскладку из localStorage
WinEngine.init()                // запуск движка (все начальные рендеры)
WinEngine.emitLayout()          // принудительно разослать 'layout' + обновить таскбар

WinEngine.desktop()             // узел #desktop
WinEngine.isMobile()            // body.mobile-layout?
WinEngine.windows()             // NodeList всех .window
WinEngine.windowsOf(id)         // NodeList всех .window[data-wid="id"]
WinEngine.countOf(id)           // число окон этого типа
WinEngine.setTaskbarMode(mode)  // 'trade' | 'sandbox' → блок режима в таскбаре
```

### Примеры

```js
WinEngine.open('chart');                        // открыть/сфокусировать (single)
WinEngine.open('chart', { force: true });       // принудительно второй экземпляр
WinEngine.open('trade');                        // передать в activate параметры инструмента
WinEngine.on('layout', () => resizeMyWidget()); // перерисовка при изменении геометрии
```

## 5. Структура окна и шаблон (template)

```html
<div class="window hidden" data-x="400" data-y="10" data-w="620" data-h="470">
  <div class="window-head">
    <span class="wtitle title">Заголовок окна</span>
    <div class="c-tools"> ...кнопки/селекты панели... </div>
    <div class="wbtns">
      <button class="wbtn min"  data-waction="min">–</button>
      <button class="wbtn max"  data-waction="max">▢</button>
      <button class="wbtn"      data-waction="close">✕</button>
    </div>
  </div>
  <div class="window-body"> ...содержимое... </div>
</div>
```

Правила:

- **Корень**: `.window.hidden` (движок снимает `hidden` при открытии) + `data-x data-y data-w data-h`
  (стартовое позиционирование/размер; по умолчанию 400×300 в центре).
- `data-wid` и `data-uid` движок проставит сам (`data-wid` — тип, `data-uid` — уникальный id экземпляра).
- Живая область — `.window-body` (главный скроллер: `overflow-y:auto`, `touch-action:pan-y`).
- Внутри виджета **не применяйте прямых `document.getElementById(...)`** — только из корня окна
  через `node.querySelector(...)`. Иначе при нескольких окнах одного типа будут конфликты DOM.
  Если нужен `id` — делайте его уникальным на экземпляре (суффикс от `node.dataset.uid`).

### Кнопки шапки (window chrome)

Движок сам вешает логику на `.wbtn` с `data-waction`:

- `data-waction="min"` — свернуть/развернуть (текст кнопки меняет движок).
- `data-waction="max"` — развернуть на весь рабочий стол / восстановить.
- `data-waction="close"` — закрыть (вызовется `def.destroy`).

## 6. Тулбары в шапке (auto-collapse)

Панель шапки определяется классом контейнера:

- `.c-tools`
- `.chart-tools`
- `.ops-tools`

Любой из них **автоматически** включается в механизм складывания (`wireCollapsibleToolbar`):

- Элементы панели, не помещающиеся по ширине при ресайзе окна, переносятся в выпадающее меню
  под кнопку «▾» (`.tb-more`).
- В меню кладутся **клоны** скрытых элементов; клики / изменения `<select>` **делегируются оригиналу**
  (который остаётся в DOM, чтобы селекторы виджета продолжали работать) и закрывают меню.
- Разделители `.tb-sep` переносятся группой и прячутся на концах.
- Пересчёт идёт на `ResizeObserver` окна (с debounce) и при изменении раскладки.

Элементы панели:

```html
<div class="c-tools">
  <button class="cbtn" ...>Кнопка</button>
  <select class="tiny-select">...</select>
  <span class="tb-sep" style="color:var(--faint);margin:0 2px">|</span>
</div>
```

- Обычные кнопки тулбара — класс `.cbtn`.
- Сколько бы элементов ни было — не влезающие уедут в меню «▾», селекты там работают нативно.

## 7. Событие `'layout'`

`WinEngine.on('layout', cb)` — подписка на перерисовку геометрии.

- `cb()` вызывается после любых изменений раскладки: ресайз, драг, открытие, закрытие, фокус,
  свернуть/развернуть — везде, где движок вызвал `emitLayout()`.
- Нужно для перерисовки: например, `chart.js` подписывается
  `WinEngine.on('layout', resizeCharts)`, чтобы перерисовывать график при смене размера любого окна.
- `emitLayout` вызывает все listener'ы в try/catch: ошибка в одном не ломает остальные и не бьёт renderTaskbar.
- **Не злоупотребляйте**: событие частое. Держите обработчики лёгкими / с debounce.

## 8. Драг и ресайз окон

### Десктоп (мышь) — interact.js
- Перетаскивание — за `.window-head` (allowFrom), ограничено в `#desktop`.
- Ресайз — за границы окна (edges: left/right/bottom). Минимальный размер:
  - `trade` — 220×120, максимальная ширина 340;
  - остальные — 200×120 (без верхнего ограничения);
- Модификаторы держат окно внутри `#desktop`.

### Тач-устройство (сам движок, без interact)
Так как `isTouchDevice()` истинно, движок включился сам:

- **Движение пальца по заголовку** — перетаскивание окна.
- **Долгий тап (~450 мс) по заголовку** — вход в режим ресайза:
  - окно получает класс `.resize-mode` (яркая рамка) и 8 ручек `.resize-handle` по периметру;
  - **рамка и ручки остаются** после отпускания пальца;
  - тяга за ручку меняет размер (угловые — обе оси, боковые — одну), с ограничением по `#desktop`;
  - **выход**: повторный тап по заголовку либо тап в любом месте вне окна.
- Пока тянута ручка, события ловятся на уровне `document`, пальцу можно уходить за край окна.

## 9. Ярлыки рабочего стола

Контейнер — `#shortcuts` внутри `#desktop` (движок заполняет его сам).

- Виджеты с `shortcut !== false` становятся ярлыками автоматически (`renderShortcuts`).
- Ярлык: иконка сверху, `label` снизу; **двойной клик/тап — открыть окно**.
- Перетаскивание — перемещение ярлыка; при выделенной группе — всех выделенных сразу.
- Выделение:
  - **клик** — выбрать один;
  - **Ctrl/Cmd+клик** или **долгий тап** на ярлыке — мультивыбор;
  - **мышью в пустоте рабочего стола** — выделение рамкой (marquee), Ctrl/Cmd — аддитив.
- **Delete** — удалить выбранные ярлыки (в `deletedShortcuts`).
- В старт-меню есть «Вернуть ярлыки на рабочий стол» и «Сброс раскладки».

Хранение: `desktopShortcuts` (координатор), `selectedShortcuts`, `deletedShortcuts` (localStorage).

## 10. Старт-меню

Кнопка «🪟 Пуск» → выпадающий список. Содержит автоматически:

- Все виджеты с `startMenu !== false` (клик — открыть окно, меню закрывается);
- разделитель;
- «Сброс раскладки» (чистит все данные геометрии и делает reload);
- «Вернуть ярлыки на рабочий стол» (очищает `deletedShortcuts`).

Закрывается кликом вне меню или по `Escape`.

## 11. Таскбар (окна + трей)

Строка внизу: кнопка «🪟», секция `#tbWindows`, `.spacer`, трей `#tbTray`.

- **Кнопки окон** (`#tbWindows`): для каждого открытого окна — `.tb-btn` с иконкой и названием;
  класс `.active` у активного, `.min` у свёрнутого. Клик → свернуть/развернуть/фокус.
- **Группировка**: если кнопки не помещаются по ширине, они схлопываются в одну кнопку «🗗 Окна»
  с выпадашкой (поверх всего).
- **Трей** (`#tbTray`): режим (`#tbMode`.), часы (`#tbClock`), дата (`#tbDate`). Часы — `startTaskbarClock` (раз в 10 сек).

`setTaskbarMode(mode)` обновляет блок режима таскбара (`'trade'`/`'sandbox'`, с точкой-индикатором).

## 12. Раскладка и storage

- **Ключи localStorage:**
  - `windowLayout` — массив `{ uid, wid, x, y, w, h, minimized }` всех открытых окон;
  - `desktopShortcuts`, `selectedShortcuts`, `deletedShortcuts` — ярлыки;
  - прочие (`user`, настройки виджетов) — в `core.js` и файлах каждый.
- `open()`/`close()` сами вызывают `saveLayout()`; при инициализации `restore()` восстанавливает окна
  сохранённой конфигурации (`force: true`).
- «Сброс раскладки» чистит релевантные ключи и делает `location.reload()`.

## 13. Мобильная адаптация

- Порог: `window.innerWidth <= 820` → body получает `mobile-layout`.
- `applyMobileLayout()` вызывается при `resize` (и при init). На `resize` вызывается и `renderTaskbar`.
- В `mobile-layout`: `#desktop{overflow:hidden}`, окна не максимизируются — только прижимаются в экран;
  свои медиа-правила в `@media (max-width:820px)` и `@media (max-width:480px)`.
- `WinEngine.isMobile()` доступен видджетам.

## 14. Конфликт DOM при 2+ однотипных окнах

Правила, чтобы несколько окон одного типа жили без конфликтов:

1. У каждого окна уникальный id на инстанс: `data-wid` (тип) + **`data-uid`** (уникальный id экземпляра).
2. Вся логика — из корня окна: `node.querySelector/querySelectorAll/addEventListener` — НЕ
   глобальные `document.getElementById`.
3. Если нужен `id` внутри template (`<input id="orderQty">`) — сделайте уникальным на экземпляре
   (суффикс по `node.dataset.uid`) или всегда отталкивайтесь от `node`.
4. Все глобальные подписки снимайте в `destroy`, чтобы закрытие окна не нарушало остальные.

С этими правилами количество окон одного типа ограничено не со стороны движка.

## 15. Как добавить новый виджет (чек-лист)

1. Создать файл `public/js/myWidget.js`.
2. Объявить `template` по §5 (корень `.window.hidden` + `data-*`).
3. `WinEngine.register({ id,title,label,icon,template,setup,destroy,onFocus })`:
   - в `setup` — инициализация содержимого через `node` (не глобально);
   - в `destroy` — очистка (таймеры, listeners);
4. Подключить `<script src="/js/myWidget.js">` в `index.html` **до** `core.js`.
5. Если надо реагировать на ресайз — `WinEngine.on('layout', onLayout)`.
6. Открыть: автоматически через ярлык/старт-меню (если флаги не запрещают) или программно `open('myWidget')`.

Если старые окна «не видят» новую раскладку — почистите `localStorage['windowLayout']`
или нажмите «Сброс раскладки» в Пуск.

## 16. Тонкости и заметки

- `interact.js` только для десктопа: `isTouchDevice()` включает собственный «долгий тап → режим ресайза»,
  а `interact` drag/resize на тач-устройствах отключён.
- `.window` — `touch-action:manipulation`; `.window-head` — `touch-action:none` (не скроллится браузером).
- Минимальный размер окна: `trade` 220×120 (max ширина 340), остальные 200×120.
- На мобильных окна не максимизируются — только подгонка в пределы экрана.
- При сомнениях — читайте исходник `window-engine.js` и комментарии прямо в коде движка (они содержат
  пояснения ко всем непростым местам: тулбар, touch resize, taskbar-меню).
